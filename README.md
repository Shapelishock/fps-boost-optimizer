## 📖 About

FPS Boost Optimizer automatically tunes render settings, entity culling, and chunk loading parameters to maximize frame rate on your hardware profile.

---

## ✨ Features
<a name="features"></a>

- **Auto Profile** — detects GPU/CPU and applies optimal preset.
- **Entity Culling** — skips rendering off-screen entities.
- **Smart Chunk Loading** — prioritises visible chunks over hidden ones.
- **Dynamic FOV Limiter** — reduces FOV strain without capping FPS.
- **Frame Cap** — configurable FPS cap to reduce GPU heat.
- **FPS Graph** — live frame-time histogram.
